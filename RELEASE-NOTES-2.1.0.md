# PrazyCron 2.1.0

PrazyCron 2.1.0 is the first publication-ready open-source release.

## Highlights

- English interface and dark theme by default.
- Opaque, high-contrast application icon.
- Graphical and terminal interfaces for Cron jobs and systemd timers.
- Validation, backups, diff previews, next-run calculations, history, diagnostics, conflict detection, environment editing, and run-now output.
- One-command GitHub repository creation and release publishing with GitHub CLI.
- Automated tests, DEB builds, release assets, checksums, issue templates, security policy, and contributor documentation.
- Experimental packaging templates for Snap and Flatpak evaluation.

## Installation

Download `prazycron_2.1.0_all.deb` from the release and run:

```bash
sudo apt install ./prazycron_2.1.0_all.deb
```
