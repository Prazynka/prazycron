# Changelog

All notable changes to PrazyCron are documented here. The format follows Keep a Changelog and the project uses semantic versioning.

## [Unreleased]

## [2.1.0] - 2026-08-04

### Added
- One-command GitHub publication scripts using GitHub CLI.
- Automated repository creation, initial commit, tag, release, topics, and release-asset upload.
- Experimental Snap and Flatpak packaging templates for distribution work.
- A self-contained publisher bundle for the first public release.

### Changed
- Prepared project metadata and documentation for the first public open-source release.


## [2.0.2] - 2026-08-04

### Changed
- English is now the default language for new and non-explicit legacy configurations.
- The dark theme remains the default appearance.
- Replaced the transparent launcher icon with an opaque, high-contrast icon that is easier to identify on the desktop and panel.
- Added complete GitHub project metadata, contributor documentation, issue templates, CI, release automation, and release tooling.

### Fixed
- Standardized language fallbacks in GUI, TUI, CLI output, schedule descriptions, and explanation providers.

## [2.0.1] - 2026-08-04

### Fixed
- Completed Polish translations for the 2.x interface and removed mixed-language labels.
- Removed development-process attribution from source and package metadata.

## [2.0.0] - 2026-08-04

### Added
- Cron and systemd timer management in one application.
- Validation, diff preview, future-run calculations, run-now output, execution history, overlap protection, diagnostics, environment editing, tags, templates, and read-only protection.

## [1.4.0] - 2026-08-04

### Added
- Initial public build with GUI, TUI, backups, source preview, sorting, localization, and offline Cron analysis.
