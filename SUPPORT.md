# Support

For installation problems, unexpected behavior, and feature requests, open an issue at:

https://github.com/Prazynka/prazycron/issues

Before reporting a problem, collect:

```bash
prazycron --version
python3 --version
uname -a
systemctl status cron --no-pager
prazycron --diagnose
```

Remove API keys, email addresses, private commands, usernames, and sensitive paths from logs before posting them publicly.
